## Stage6 / Stage5 angular final BA without normalize Jacobian ablation

本次实验用于验证：之前 tangent-plane angular BA 的变化是否主要来自优化 Jacobian 中的单位向量归一化导数：

```text
d normalize(y) / d y = (I - y_hat y_hat^T) / ||y||
```

实现方式不是永久删除该 Jacobian，而是新增消融开关。默认仍使用正确 Jacobian；本实验显式关闭：

- Stage6: `--stage6-spherical-use-normalize-jacobian false`
- Stage5: `--backend-angular-use-normalize-jacobian false`

需要注意：本实验仍然保留 angular residual 本身的 ray normalization，即 `b_pred = normalize(X_cam)`。关闭的只是优化器使用的解析 Jacobian 中的 normalize 导数，因此应表述为 `identity normalize-Jacobian proxy` 消融，而不是“非归一化 angular residual”。

### Baseline freeze: frontend board rescue integrated into Stage5 / Stage6

当前前端检测器的 board rescue 已经冻结为内参 Stage5 与外参 Stage6 baseline 的一部分。

默认 baseline 行为：

- 启用 geometry-prior missing-board rescue；
- rescue 不是直接使用投影角点，而是用几何预测提供 ROI；
- 在 ROI 内执行 spherical / local corner refine；
- 要求图像 edge evidence；
- 允许 geometry-only pose-refit，但必须通过 pose / edge / outer RMSE consistency；
- 通过后可作为 observation 进入训练与验证 frontend；
- 训练集与验证集默认都开启 rescue，以避免真实存在的 board 因 raw detector 漏检而被评价忽略。

- 只关闭 rescue observation:
  `--stage5-geometry-prior-rescue-disable-use-as-observation`
  `--stage6-geometry-prior-rescue-disable-use-as-observation`
- 关闭 geometry-only pose-refit:
  `--stage5-geometry-prior-rescue-disable-geometry-only-pose-refit`
  `--stage6-geometry-prior-rescue-disable-geometry-only-pose-refit`
- 关闭 spherical refine:
  `--stage5-geometry-prior-rescue-disable-spherical-refine`
  `--stage6-geometry-prior-rescue-disable-spherical-refine`
- Stage6 诊断用 raw holdout:
  `--stage6-disable-geometry-prior-rescue-for-holdout`

注意：

主实验应默认训练集与验证集都开启 rescue。若需要分析 RMSE 是否受验证集观测集合变化影响，可以额外报告 raw-holdout ablation，但不应替代主指标。
