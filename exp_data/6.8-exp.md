# 6.8-exp: Stage6 Pair Cohesion 与 Backend Board 分布实验记录

## 背景

本轮实验关注 Stage6 双目外参中一个具体问题：原先的 pair-board trial selection 是以 `(stereo pair, board)` 为独立候选进行筛选。这样虽然每个候选本身可以通过 short BA gate，但最终进入 backend 的某些 stereo pair 可能只携带 1 个 board。这个现象和 Stage5 内参中遇到的“单 frame / 单 board 约束不够稳定”问题类似。

因此，本轮实验引入 Stage6 版 `pair cohesion` / companion rescue：

- 常规 pair-board trial selection 完成后，检查已进入 backend 但 board 数不足的 stereo pair。
- 对同一 pair 下其它 shared board candidate 做 companion rescue。
- companion 仍必须通过 short global sparse BA 的 RMSE delta、camera RMSE delta、baseline rotation / translation stability gate。
- 不强制 drop single-board pair；本轮主实验使用 `single_board_pair_policy=audit`。
- 后续版本将 `max_companions_per_pair=0` 的含义改成参考 Stage5 内参：按该 pair 实际 shared board capacity 自动补齐，而不是只补到 `min_boards_per_pair=2`。

核心假设是：提高每个 backend stereo pair 中的 shared board 覆盖度，可以让外参约束更接近 multi-board / multi-view 的稳定观测，从而改善验证集上的外参泛化能力。

## 实验设置

数据 split：

- training: `stereo_dataset_20260430_144928`
- holdout: `stereo_dataset_20260430_134853`
- measurement source: `all_valid`
- solver: `global_sparse_ba`
- 主评价指标: `extrinsic-only holdout RMSE`
- 辅助诊断指标: training RMSE
- local stereo outer RMSE hard filtering: disabled
- shared board quality gate: audit / non-hard filtering 口径

说明：本实验不再记录 ordinary holdout 作为判断指标。ordinary holdout 会混入 holdout multi-board scene / board pose 迁移等因素，不利于单独判断双目外参泛化能力。后续关于 Stage6 外参泛化的主结论，以 `extrinsic-only holdout RMSE` 为准。

共同保留的有效性检查：

- synchronized stereo pair 有效
- pair reachable / initialized
- shared board 可评估
- 点数足够
- projection 有效
- short BA solver 无 NaN / divergence
- baseline rotation / translation 没有异常跳变

### 可截取报告段落：每 pair board 分布改善与 RMSE 提升

为了验证 backend 中每个 stereo pair 的 board 覆盖度是否会影响外参泛化，我们在 `144928 -> 134853` split 上做了逐步 ablation。原始 no-cohesion baseline 中，backend 共选择 48 个 stereo pair、90 个 pair-board，其中 21 个 pair 只包含 1 个 board，board 数分布为 `1:21, 2:14, 3:11, 4:2`，对应的 extrinsic-only holdout RMSE 为 `4.26159 px`。引入 pair cohesion 后，随着 rescue 目标从 “补到 min=2” 逐步扩展为 “补齐该 pair 实际可见 shared boards”，每 pair board 分布持续变得更完整：under-target rescue 版本选择 230 个 pair-board，single-board pair 降到 1 个，board 数分布变为 `1:1, 3:1, 4:4, 5:42`，extrinsic-only holdout RMSE 降到 `3.69549 px`。进一步引入 Kalibr-style valid traversal 后，backend 选择 284 个 pair-board，single-board pair 降到 0，board 数分布变为 `2:2, 3:4, 4:7, 5:48`，extrinsic-only holdout RMSE 继续下降到 `3.64505 px`，相对 baseline 总改善 `0.61654 px`。

这组递进实验说明，在当前 split 上，RMSE 的下降不是由单次参数扰动偶然造成的，而是与 backend pair-board 覆盖度的系统性提升一致：从 no cohesion 到 min=2 rescue、auto capacity、relax cap gates、under-target rescue，再到 Kalibr-style valid traversal，5-board pair 数量持续增加，single-board pair 数量最终降为 0，extrinsic-only holdout RMSE 也从 `4.26159 -> 4.14022 -> 3.89517 -> 3.86323 -> 3.69549 -> 3.64505` 持续下降。值得注意的是，training RMSE 同期从 `1.24952` 上升到 `1.73859`，因此该收益不能简单解释为训练集过拟合；更合理的解释是，更完整的同 pair multi-board 约束降低了外参被少数 board 或局部视角牵引的风险，从而提升了 holdout 上的外参重投影表现。

## 验证过程记录

本轮验证不是只比较两个最终数值，而是逐步放开 Stage6 backend 中同一 stereo pair 的 shared board 覆盖度，并观察 `extrinsic-only holdout RMSE` 是否随 board 分布改善而同步下降。

递进过程如下：

1. `no cohesion baseline` 保持原始 pair-board 独立选择，backend 中 21 个 pair 只有 1 个 board，`extrinsic-only holdout RMSE=4.26159`。
2. `pair cohesion audit` 只尝试把不足 2 个 board 的 pair 补到 `min=2`，single-board pair 从 21 个降到 1 个，RMSE 降到 `4.14022`。
3. `auto capacity` 将 rescue 目标扩展到该 pair 实际可见 shared board 数，但仍受普通 cap gate 影响，5-board pair 增加到 9 个，RMSE 降到 `3.89517`。
4. `auto capacity + relax cap gates` 证明很多 companion board 原先不是几何无效，而是被 pair/board cap gate 提前挡住；绕过 cap gate 后 5-board pair 增加到 15 个，RMSE 降到 `3.86323`。
5. `under-target rescue` 把触发条件改成 `selected_board_count < actual_shared_board_count`，尽量纳入同 pair 下所有可通过 short BA 的 shared board；最终 5-board pair 增加到 42 个，2-board pair 降到 0，RMSE 降到 `3.69549`。
6. `Kalibr-style valid traversal` 不再固定只尝试前 `N` 个 candidate，而是遍历所有 valid pair-board candidate，并由 short BA / batch acceptance 决定是否接收；最终 selected pair-board 增加到 284，single-board pair 降到 0，5-board pair 增加到 48 个，RMSE 继续降到 `3.64505`。

这个递进关系说明：在当前 split 上，backend board 分布从稀疏的 1/2-board pair 改善为以 5-board pair 为主后，外参在验证集上的泛化指标持续改善。与此同时 training RMSE 从 `1.24952` 上升到 `1.73859`，因此该收益不能简单解释为训练残差被压低，更合理的解释是：更多同 pair shared board 提供了更完整的空间约束，减少了外参被少数 board / 少数局部视角牵引的风险。

覆盖度变化：

- `134853 -> 144419`: pair-board 从 90 增加到 185，5-board pair 增加到 33 个，但 `extrinsic-only holdout RMSE` 从 `3.29979` 退化到 `3.39531`，变化为 `+0.09552 px`。
- `144419 -> 144928`: pair-board 从 90 增加到 173，5-board pair 增加到 23 个，`extrinsic-only holdout RMSE` 从 `3.05865` 改善到 `2.58439`，变化为 `-0.47426 px`。

这个跨 split 复核说明：增加同 pair board 覆盖度确实稳定改变了 backend 分布，但它对外参泛化不是无条件正收益。`144928 -> 134853` 和 `144419 -> 144928` 都有明显收益；`134853 -> 144419` 则轻微退化。尤其是 `134853 -> 144419` 中 training RMSE 也从 `1.41928` 上升到 `1.52237`，说明被 rescue 的 companion board 虽然通过了 short BA gate，但可能仍引入了对该 holdout split 不利的约束偏移。

一个值得单独记录的现象是：当 `134853` 作为训练集时，后续更强的 valid traversal 也呈现同样趋势，即每 pair board 分布进一步完善，但 cross-split 的 `extrinsic-only holdout RMSE` 继续上升。当前观测上，`134853` 的采集视角以非近距离、非边界视角为主，而 `144419` / `144928` 中近距离和图像边界视角相对更多。因此，对 `134853` 来说，补齐更多同 pair board 更像是在训练集原有中远距离视角分布内加密约束，而不一定补足验证集需要的近距离 / 边界几何约束。换句话说，pair-board 覆盖度提升只有在新增 board 同时带来有效视角多样性时，才更可能转化为 holdout RMSE 改善。

因此，当前更稳妥的判断是：`pair cohesion under-target rescue` 是一个有效的 coverage 增强机制，但还不能直接作为无条件默认主策略。它需要进一步加入 companion 质量分层、split-level ablation，或在 final BA 中对 rescue companion 做更细的权重 / 审计策略。

## 结论

`144928 -> 134853` 的五组递进实验支持当前判断：提高 backend 中每个 stereo pair 的 board 覆盖度后，Stage6 外参在 `extrinsic-only holdout` 上的泛化能力有明显提升。

具体表现是：

- single-board backend pair 从 21 个降到 1 个。
- selected pair-board 从 90 增加到 230。
- board 数分布从 `1:21, 2:14, 3:11, 4:2` 改善到 `1:1, 3:1, 4:4, 5:42`。
- 2-board pair 从 15 个进一步降到 0。

### 可截取报告段落：valid traversal 进一步提升 pair-board 覆盖

在新增的 Kalibr-style valid-candidate traversal 实验中，Stage6 不再固定只尝试前 `N` 个 pair-board candidate，而是遍历全部 valid candidates，再通过 short BA 和 batch acceptance 判断是否接收。该修改进一步提高了 backend 中每个 stereo pair 的 board 覆盖度。以 `144928` 作为训练集时，no-cohesion baseline 的 board 分布为 `1:21, 2:14, 3:11, 4:2`，selected pair-board 为 `90`；under-target rescue 后变为 `1:1, 3:1, 4:4, 5:42`，selected pair-board 为 `230`；valid traversal 进一步变为 `2:2, 3:4, 4:7, 5:48`，selected pair-board 为 `284`，single-board pair 降为 `0`。与此对应，`144928 -> 134853` 的 extrinsic-only RMSE 从 `4.26159` 降到 `3.69549`，再降到 `3.64505`；`144928 -> 144419` 则从 `3.61371` 降到 `3.35449`，再降到 `3.33116`。

`144419` 作为训练集时也呈现类似趋势：valid traversal 将 board 分布提升到 `1:1, 3:2, 4:2, 5:36`，相比 no-cohesion baseline 的 `1:6, 2:20, 3:12, 4:2` 明显减少了 1/2-board pair，并显著增加 5-board pair。对应地，`144419 -> 134853` 的 extrinsic-only RMSE 从 `4.02294` 降到 `3.55313`，再降到 `3.41472`；`144419 -> 144928` 从 `3.05865` 降到 `2.58439`，再小幅降到 `2.57826`。

因此，这批实验支持一个更清晰的判断：当 valid traversal 能把 backend 分布从大量 1/2-board pair 推向以 5-board pair 为主，并且新增 board 覆盖到足够多样的视角 / 距离区域时，外参 holdout RMSE 通常会下降。六个 cross split 中有四个相对 no-cohesion baseline 取得改善，并且这四个改善组也都优于旧的 under-target rescue。需要保留的例外是 `134853` 作为训练集的两个 cross split：虽然 board 分布同样从 `1:9, 2:18, 3:7, 4:6` 提升到 `1:1, 3:1, 4:1, 5:37`，但 `134853 -> 144419` 和 `134853 -> 144928` 分别从 no-cohesion 的 `3.29979 / 2.70689` 上升到 `3.41818 / 2.94947`。结合数据采集观察，`134853` 中近距离和图像边界视角较少，新增 pair-board 更可能是在原有中远距离视角分布内加密约束，而不是补足对近距离 / 边界 holdout 的泛化能力。这说明“更多 board 覆盖”不是无条件充分条件；它需要和 companion 质量、左右相机 residual balance、视角分布多样性共同约束。总体上，valid traversal 强化了“每 pair board 覆盖改善能够带来 RMSE 提升”的主要证据，同时也暴露了 `134853` 训练集下仍需质量分层和视角多样性约束的边界情况。

### 方法定义

Stage5 frozen baseline v3 的核心逻辑是：

先用当前 Stage5 主流程得到稳定 seed bundle；随后在 `kalibr_style_batch` 模式下遍历所有 valid `(frame, board)` candidates，以 residual health + coverage / balance proxy 做 batch acceptance；一旦某个 frame 中已有 board 被接受，继续触发 frame cohesion companion completion，尽量把该 frame 实际观测到的其它 board 也补入 backend，但 companion 仍需通过 tentative backend / residual health 检查。

该 baseline 暂时不采用 intrinsics-Jacobian info-gain proxy 作为主方法，因为当前实验中该分支容易把大量 frame 纳入 backend，导致 selection 失去足够筛选性；后续可作为探索性 ablation 保留。
